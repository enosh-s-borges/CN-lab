-> A. To find the Host name, IP address, physical address, subnet mask, default gateway, and other network information, you can use Terminal (Linux/Mac). Here are the steps:
1. Open the Terminal application.
2. Type the command for:

| Information                   | Command      |
| ----------------------------- | ------------ |
| **Host name**                 | `hostname`   |
| **IP address**                | `ip -4 addr` |
| **Physical (MAC) address**    | `ip link`    |
| **Subnet mask**               | `ip -4 addr` |
| **Default gateway**           | `ip route`   |
| **Other network information** | `ip addr`    |

-> B. To identify TCP connections, listening ports, Ethernet statistics, the IP routing table, and IPv4 statistics, you can use the `ss` command for modern Linux systems. Here are the steps:
1. Open the Terminal application.

| Requirement             | Command         | What it shows                |
| ----------------------- | ------------    | ---------------------------- |
| **TCP connections**     | `ss -t`         | Active TCP connections       |    [Note: use `ss -tun` to include UDP connections as well]
| **Listening ports**     | `ss -tuln`      | TCP/UDP listening ports      |
| **Ethernet statistics** | `ip -s link`    | RX/TX packets, errors, drops |
| **IP routing table**    | `ip route`      | Routing table                |
| **IPv4 statistics**     | `ip -s -4 addr` | IPv4 network statistics      |
